¿Qué es el VibeCoding?
Programar sin saber programar. Crear sin código.

El VibeCoding es la nueva forma de construir aplicaciones: describes en lenguaje natural lo que quieres, y la IA escribe, revisa y mejora el código por ti. Tú diseñas la lógica, decides las funcionalidades, y validas el resultado. Claude Code es el asistente de programación más avanzado del mercado para este flujo. CoWork coordina el proyecto. Tú eres el director, no el programador.

🤖
Claude Code
El asistente de programación de Anthropic integrado en VS Code. Escribe, refactoriza y depura código por ti.
⚡
CoWork
Coordina el proyecto, genera documentación, prueba funcionalidades y gestiona los pasos del desarrollo.
🛠️
VS Code
El entorno de desarrollo estándar, gratuito y ampliamente utilizado. Claude Code vive dentro de él.
🚀
Tú, el Director
Tu rol es definir, revisar y validar. La IA escribe el código. Tú decides qué se construye y por qué.
⚠️ Nivel requerido: Es necesario haber completado el Curso 2 — IA para Directivos: Automatización sin Código — o tener experiencia equivalente en el uso de Claude y automatizaciones. No se requiere experiencia en programación.

Ejemplos de aplicaciones que se pueden construir
Aplicaciones reales en un día.

Estos son ejemplos del tipo de herramientas que los participantes han construido o podrán construir en el curso. Cada participante trabaja sobre su propio caso de uso.

Ejemplo
Analizador de competencia
Introduce el nombre de tu empresa y tus competidores. Genera automáticamente un informe de posicionamiento con comparativa de precios, mensajes clave y puntos débiles.
Construcción estimada: 90 min
Ejemplo
Generador de propuestas comerciales
Formulario interno que recoge los datos del cliente y proyecto. Genera automáticamente una propuesta comercial en PDF con el tono y estructura de tu empresa.
Construcción estimada: 2 h
Ejemplo
Dashboard de seguimiento de proyectos
Panel visual que lee datos de una hoja de cálculo y muestra el estado de los proyectos activos con alertas automáticas por retrasos o desviaciones.
Construcción estimada: 2.5 h
Ejemplo
Clasificador de emails de soporte
Herramienta que procesa los emails de un buzón de soporte, los clasifica por tipo e urgencia, y genera una respuesta sugerida para cada uno.
Construcción estimada: 2 h
Programa · 2 sesiones de 4 horas
Mañana: entorno y primeros pasos. Tarde: construye tu app.

El curso sigue un proyecto real de principio a fin. Por la mañana aprendes el entorno y la metodología. Por la tarde aplicas todo para construir y desplegar tu propia aplicación. Saldrás con algo funcionando.

Sesión 1 · 9:00–13:00 h.
Entorno, Metodología y Primer Prototipo
Mañana · 4 horas
Preparación del entorno
  • Instalación de VS Code y Claude Code (si no está hecho previamente)
  • Estructura de un proyecto: carpetas, archivos y cómo se organiza el código
  • Primer contacto: pedirle a Claude Code que explique un archivo existente
  • Cómo dar instrucciones efectivas a Claude Code: claridad, contexto, ejemplos
La metodología VibeCoding
  • Diseño previo en lenguaje natural: el briefing que define todo lo que se va a construir
  • Ciclo de trabajo: describe → revisa → aprueba → itera
  • Cómo usar CoWork para coordinar tareas, revisar código y gestionar el progreso
  • Git básico con IA: guardar versiones y recuperar cambios sin perder trabajo
Construir el primer prototipo
  • Cada participante describe su aplicación en 1 página de requisitos
  • Claude Code genera la estructura inicial del proyecto
  • Primera versión visible en el navegador en menos de 30 minutos
  • Añadir funcionalidades: formularios, botones, lógica básica
⚡ EJERCICIO: tu primera aplicación visible en el navegador antes de comer
🤖 Claude Code ⚡ CoWork 🛠️ VS Code
Momento WOW El participante describe su aplicación en lenguaje natural. Claude Code genera el código. En menos de 20 minutos, hay una pantalla real funcionando en el navegador. «No he escrito ni una línea de código y esto ya funciona.»
Sesión 2 · 15:00–19:00 h.
Construye, Mejora y Despliega tu Aplicación
Tarde · 4 horas
Completar la aplicación
  • Continuar desde el prototipo de la mañana: añadir funcionalidades pendientes
  • Integrar Claude o la API de IA en la aplicación para análisis o generación de texto
  • Depurar errores con Claude Code: describe el problema, Claude lo resuelve
  • Mejorar el diseño visual sin tocar el CSS manualmente
CoWork como coordinador de proyecto
  • Gestión del avance: qué está hecho, qué falta, qué hay que priorizar
  • Generar documentación automática de la aplicación para el equipo
  • Revisión de código: CoWork como auditor que detecta problemas antes de desplegar
Despliegue y entrega
  • Publicar la aplicación en la web (Vercel o similar, gratuito y sin configuración)
  • Compartir el enlace con el equipo desde el mismo día
  • Cómo mantener y mejorar la aplicación después del curso
  • Cuándo escalar: límites del VibeCoding y cuándo necesitas un desarrollador
Cierre y siguientes pasos
  • Presentación rápida de cada aplicación construida (2 min por participante)
  • Recursos para seguir aprendiendo y construyendo en solitario
  • Plan de acción: qué construirás en las próximas 4 semanas
⚡ EJERCICIO: tu aplicación publicada y accesible desde cualquier dispositivo
